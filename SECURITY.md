# Security and responsible research

This repository covers **isolated, offline analysis**. No connection to a physical vehicle is required or encouraged.

Do not test on moving vehicles, inject CAN traffic, disable vehicle security features, distribute secrets, or flash production head units based on experimental results.

Report sensitive vulnerabilities privately to the affected vendor through an appropriate disclosure channel rather than posting exploit details or keys in public Issues.

Review every patch before running it. Scripts should use disposable overlays, explicit paths, least privilege and clear cleanup steps. All results are experimental and may be unsafe or incorrect if applied to a physical system.
