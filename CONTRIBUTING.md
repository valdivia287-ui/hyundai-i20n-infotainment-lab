# Contributing

Thanks for helping! We welcome legally shareable documentation, original scripts, reproducible tests and synthetic fixtures concerning Linux graphics, Qt 5.4, Wayland IVI and offline automotive UI emulation.

1. Open an Issue with the expected behavior, evidence, reproduction steps and environment details.
2. Prefer small, focused pull requests with tests and a brief explanation.
3. Mark evidence clearly: **runtime verified**, **static analysis**, or **hypothesis**.
4. Confirm that code/assets you submit are yours to publish, and add attribution, upstream license and source revision for any reused implementation (see [PROVENANCE.md](PROVENANCE.md)).
5. Redact personal paths, VINs, IDs, IPs, credentials, raw traces and logs.
6. **Do not upload** OEM firmware, binaries, maps, Hyundai QML, textures, encryption keys, core dumps or disk images.
7. Do not submit tools or instructions for flashing live vehicles, defeating security protections, interfering with CAN traffic, or safety-critical vehicle systems.

Original contributions are intended to be MIT-licensed; upstream works keep their own licenses. Do not claim that MIT covers third-party proprietary materials.
