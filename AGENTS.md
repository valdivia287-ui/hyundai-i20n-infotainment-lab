# Cross-agent handoff

This repository supports multiple AI coding agents. Follow the same instructions in [CLAUDE.md](CLAUDE.md) and the project-specific status in [docs/AI-HANDOFF.md](docs/AI-HANDOFF.md).

Do not infer access to the private firmware or VM from the public repository. Use separate branches/worktrees for parallel changes, run no hardware-vehicle tests, and preserve provenance of any upstream work.
