# Cross-agent handoff

This repository supports multiple AI coding agents. Follow the same rules as [CLAUDE.md](CLAUDE.md); current state is in [docs/STATUS.md](docs/STATUS.md) and the resume protocol in [docs/AI-HANDOFF.md](docs/AI-HANDOFF.md).

Do not infer access to the private firmware or VM from the public repository. Use separate branches/worktrees for parallel changes, keep one active guest, run no vehicle tests, and preserve provenance of any upstream work.
